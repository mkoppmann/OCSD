# Objectives for Module 6 - Error Handling

This module tests the developer for the handling of errors in application and the entire technical stack that is the part of the application.

A successful candidae can:

- Implement secure exception handling patterns that prevent information disclosure
- Design fail-secure systems that maintain security during error conditions with Secure exception handling and propagation techniques
- Configure appropriate error logging without exposing sensitive data
- Apply framework-specific error handling best practices
- Describe Fail-secure versus fail-open design principles
- Implement global and centralized error handling approaches
- Secure logging practices and sensitive data sanitization
- Describe between development and production error modes 


---

## Expected Competencies
Candidates can implement securely managed application errors and exceptions while minimizing information disclosure and maintaining application security during failure conditions. This competency would support the development of resilient, secure, and production-ready applications aligned with secure coding best practices.
