# Objectives for Module 10 - Software Supply Chain Security

This module tests the developer for the importance of software supply chain risk manifestation and how this risk is addressed in development and implementation. It is tests writing secure code to ensure vulnerabilities are not a part of the application.

Successful candidates can:

- Address OWASP Top 10 risks for applications 
- Implement checking of authenticity of upstream open source components and their respective sources
- Use SAST tools to scan code from open source tools where source code is available
- Manage software dependencies securely using SCA tools
- Manage software bill of materials (SBOM)
- Evaluate and select open source software with security and licensing considerations

---

## Expected Competencies
Candidates can select and implement secure open source components, whilst maintaining a line-of-sight view of materialisation of any supply chain risks. Candidates can write secure code and do not depend on security testing or WAF to discover vulnerabilities in their code.
