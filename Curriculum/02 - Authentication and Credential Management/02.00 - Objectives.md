# Objectives for Module 2 - Authentication and Credential Management

This module tests the understanding a developer has about authentication (various authentication protocols, implementation of the various protocols) and managing credentials (using identity providers, storing credentials and secrets, secure use of service accounts / service principals / managed identities).

A successful candidate can:

- Implement secure authentication mechanisms including SSO, MFA, and OpenID
- Apply proper credential lifecycle management practices
- Implement secure session management with appropriate cookie attributes
- Securely handle JWT tokens with proper validation and security controls
- use mutual TLS authentication securely
- implement database connection strings and are aware of the risks of doing it insecurely
- know the security benefits and security pitfalls of various authentication protocols

---

## Expected competency
Given a design, candidate can implement / develop / code requirements related to authentication securely. They know where and when to add code to authenticate human identities and non-human identities. They are aware of the API calls to be made to identity providers / identity stores such as Entra ID for authentication.
