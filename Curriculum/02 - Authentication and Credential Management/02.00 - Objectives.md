# Objectives for Module 2 – Authentication and Credential Management

This module covers how web applications verify identities, protect credentials, and maintain authenticated sessions.

A successful candidate can:

- Distinguish authentication from identification, identity proofing, and authorization
- Identify protections for passwords and other credentials throughout their lifecycle
- Distinguish authentication methods and factors for human and non-human identities
- Recognize the security properties and limitations of multi-factor authentication (MFA) and passwordless authentication
- Identify requirements for establishing, maintaining, renewing, and terminating authenticated sessions
- Distinguish single sign-on (SSO), federation, OAuth 2.0, OpenID Connect (OIDC), and Security Assertion Markup Language (SAML)
- Identify validation requirements for authentication tokens and assertions, including the JSON Web Token (JWT) format
- Identify common authentication and session failures and the test cases that reveal them

## Expected competency

Candidates can recognize whether an authentication design protects human and non-human identities, credentials, and sessions.
They can identify weaknesses in login, recovery, MFA, federation, token validation, and session handling.
