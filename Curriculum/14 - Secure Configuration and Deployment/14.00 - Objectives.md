# Objectives for Module 14 - Secure Configuration and Deployment

This module tests the understanding a developer has about secure configurations and security requirements for deployment of code.

A successful candidate can:

- Configure web servers / PaaS for web server, securely with proper access controls and file permissions
- Implement secure deployment practices for code and packages
- Remove unnecessary features, debug code, and unused dependencies before deployment
- Apply security controls for cloud-based deployment services
- Address embedded secrets, and backdoors
- Implement CI/CD hardening
- Implement code signing, commit signing, image signing

---

## Expected Competencies
Given a design, candidates can implement / develop / code requirements related to deployment. They know how to sign commits, code and images. They ensure secrets are not embedded in code, add secure configurations and harden them.
