# Objectives for Module 13 - API and Web Service Security

This module tests the developer development of API and web services.

Successful candidate can:

- Identify and mitigate OWASP API Security Top 10 vulnerabilities
- Implement secure authentication and authorization for APIs
- Apply proper input validation and rate limiting techniques for APIs
- Secure different API types including REST, GraphQL, SOAP, and gRPC
- Implement secure webhook patterns and API gateway configurations

---

## Expected Competencies
Given a design, candidates can implement / develop requirements for API and web service. The candidates write code that reduces the attack surface of an API with authentication, authorisation, input validation. They can can implement secure usage of OAuth2.0 tokens.
